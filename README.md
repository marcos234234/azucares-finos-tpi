# azucares-finos-tpi
TPI Organización Empresarial: app de pedidos y reparto

## Descripción del sistema
Aplicación de pedidos online para la panadería Azúcares Finos.
Permite a los clientes consultar productos, realizar pedidos y
seguir su entrega, y ayuda a organizar el reparto.
